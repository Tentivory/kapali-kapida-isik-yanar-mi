**Resmi bildiri:** Bu depo, insanlığın en eski ev içi gizemini çözmek için kurulmuştur.

Çünkü şaka değil. Şaka olsaydı README bu kadar uzun olmazdı.

- içeride kalan yoğurtların anayasaya uygun ışık hakkını savunur
